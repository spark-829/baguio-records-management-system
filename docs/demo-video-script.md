# Demo video script (about 3 minutes)

Record the screen at 1280×800. Speak plainly; show, don't list.

| Time | Screen | Say |
| --- | --- | --- |
| 0:00 | Login page | "This is a Records Management System I built for the Junior Software Developer role. It covers the eight modules in the job description." |
| 0:10 | Sign in as records@rms-demo.test, dashboard | "The records desk sees what's open, what's overdue and what's waiting in its office." |
| 0:25 | Register, upload a scanned letter, click Fill from document | "A letter arrives. I upload the scan, and the assistant reads it and fills in the form. Highlighted fields came from the AI; I check them before saving." |
| 0:55 | Save; record page with tracking number | "Saving issues a tracking number. Here is the routing slip with a QR code to stick on the paper copy." |
| 1:10 | Forward to Engineering | "I forward it to Engineering. Every step is recorded with who and when." |
| 1:20 | Sign in as engineering.staff, receive, add remark | "Engineering receives it and records the action taken." |
| 1:40 | Back as records officer, Records page, filters, AI search | "Finding documents: keywords, filters, or just describe what you need." |
| 1:55 | Assistant: "What documents came from Juan dela Cruz?" | "Or ask the assistant. It answers with links to each record." |
| 2:10 | Sign in as treasury.staff, ask the same question | "Treasury staff asking the same question get nothing back: access rules are enforced in the database, so the assistant can only see what this user may see." |
| 2:25 | Reports, export CSV | "Reports by status, office, type and month, exportable to CSV or print." |
| 2:35 | Admin: Users, Audit log | "Admins manage accounts, and every change and AI suggestion is in an audit log that no one can edit." |
| 2:50 | README / system analysis | "The repository includes the system analysis with the ERD and use cases, a user manual and a turnover guide. Thank you." |
