# Paper fallback

Use this when staff cannot use the system.

## When to switch to paper

- The site does not open for more than 15 minutes.
- The office internet or power is down.
- The head of office says so.

Tell all staff when you switch, and when you switch back.

## The outage logbook

Print this page. Use one line per document. Number lines from 1, and start again at 1 for each outage.

| Log no. | Date/time received | From | Subject | Type | Received by | Routed to | Entered in system (tracking no.) |
| --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |

Write the log number on the paper itself. Hand the paper to the office as normal, and write the office in "Routed to".

## After the system is back

1. For each logbook line, register the document as usual (Register page).
2. The form has no field for the date it was received. The system stamps the time you enter it. So put this in the **Short description** box: `Received during outage at <time>, logbook no. <n>`.
3. Copy the new tracking number into the last column of the logbook.
4. Tick off every line. File the logbook with the office records.
